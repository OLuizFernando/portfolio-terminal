EstudaFatec.com

Uma plataforma de estudos para o vestibular da FATEC: provas antigas
transformadas num banco de questões filtrável, simulados cronometrados, e
estatísticas que mostram qual matéria está de fato custando seus pontos.

Next.js full stack com a lógica de negócio mantida fora dos route handlers,
e dois bancos de dados porque questões e contas não querem o mesmo formato:
Postgres para usuários, sessões e respostas, MongoDB para as questões.

Os testes conversam com bancos de dados reais. Nada relacionado a banco de
dados vale a pena mockar.
